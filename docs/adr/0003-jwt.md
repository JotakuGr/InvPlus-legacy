# ADR 0003 - JWT

## Status

Aceito.

## Contexto

A API REST precisa de autenticação stateless para frontend SPA.

## Decisão

Usar Spring Security com JWT e refresh token.

## Consequências

- Escala melhor para múltiplas instâncias.
- Permissões continuam no backend.
- Refresh token exige revogação e auditoria.
