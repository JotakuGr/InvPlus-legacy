# ADR 0001 - Monólito Modular

## Status

Aceito.

## Contexto

O ERP possui muitos domínios, mas ainda está em fase de construção e validação.

## Decisão

Usar monólito modular com módulos por domínio de negócio.

## Consequências

- Menor complexidade operacional no início.
- Domínios permanecem separados no código.
- Evolução futura para microsserviços continua possível.
